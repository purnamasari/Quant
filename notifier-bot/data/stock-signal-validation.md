Generated by `npm run backtest:stock` and `npm run correlate`, universe = the
bundled `data/symbol-directory.json` (91 large-cap US stocks/ETFs), 3-year
daily history, 2-day hold. Re-run these scripts periodically — this is a
snapshot, not a permanent truth.

**Caveat:** the last 3 years were a broadly rising market for large-cap US
equities, so every bullish-tilted signal here carries some baseline market
drift, not pure edge from the pattern itself. Treat the ranking as relative
(which signals are least bad), not as proof of positive expectancy going
forward.

## Bearish/short mirror signals — tested, NOT enabled

At the user's request ("kalau signal bearishnya cukup kayanya worth buat
dimention"), 9 bearish mirror signals were added (death-cross,
ma-breakdown [reuses ma-alignment machinery inverted], macd-bearish,
volume-surge-down, momentum-laggard, mean-reversion-short, near/new-52w-low,
rebound-down, distribution) and backtested with the same methodology,
direction-aware (short PnL = -price return).

**Result: every single bearish kind was flat-to-negative expectancy** except
`new-52w-low` (+0.02%, essentially breakeven, n=359). Worst offenders:
volume-surge-down (-0.5%), momentum-laggard (-0.47%), mean-reversion-short
(-0.39%). None are enabled in `config.alertStockKinds` as a result — the
code fully supports them (every signal carries a `direction` field), but
the data doesn't back turning any into an alert trigger right now.

**Caveat:** this is very likely a reflection of the backtest window being a
broadly rising market for the last 3 years — shorting into an uptrending
tape is expected to underperform regardless of pattern quality. This is
not proof bearish patterns never work, only that they didn't in this
specific sample. Re-run this backtest periodically, especially after any
extended down/choppy period, and reconsider.

The original 3-year backtest above turned out to be a bull-market snapshot.

### Conclusion: default alert kinds changed

`mean-reversion` and `volume-surge` — two of the original four defaults —
were flipping sign between the two 5-year halves and turned negative once
a realistic trading cost was assumed. `cup-handle` also went negative
post-cost. **New default: `momentum`, `cup-forming`, `golden-cross`** —
the only three that stayed positive across both time halves AND after
cost. Even these are thin (0.01-0.04% after cost) — treat every alert as a
low-conviction, small-edge signal, not a proven system.

## Reading: what this means for the alert filter

The four highest-expectancy kinds (mean-reversion, golden-cross, volume-surge,
plus momentum/cup-forming close behind) are **also** among the least mutually
correlated — i.e. they're not just re-describing the same "stock is in an
uptrend" fact under different names. This matches the arXiv:2504.10914 paper's
warning: the highest-frequency signals here (macd-bullish 29k fires,
vcp 20.8k, ma-alignment 17.9k, near-52w-high 16.4k) also have the weakest
expectancy and the highest mutual overlap — consistent with them being
largely redundant trend re-descriptions rather than independent evidence.

**Default alert filter used by `job.js`:** `mean-reversion`, `golden-cross`,
`volume-surge`, `cup-handle` — override via code if you disagree after
reviewing this table yourself.
